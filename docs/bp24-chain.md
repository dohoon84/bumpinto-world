# BUMP24 체인 매장 — 매장 추가하기

> 브랜드 이름은 BUMP24예요(예전 BP24). 호환을 위해 코드 이름·파일 이름·`?bp24` 플래그는 그대로 두고, `?bump24=1` · `?bump24=demo`도 같은 뜻으로 받아요.

BUMP24는 건물 1층에 끼워 넣는 우리 브랜드 편의점이에요. 코드는 `src/corridor/bp24.js`, 매장 목록은 `src/corridor/bp24Locations.js`의 `BP24_PLACEMENTS`예요. 코리더 타일 매장과 정자 베이스맵 매장이 같은 목록을 써요.

## 켜는 법

| URL | 동작 |
|---|---|
| (없음) | 코리더 매장(시청점)은 꺼짐. 정자점(`bump24-jeongja`)은 켜짐 |
| `?bp24=1` · `?bump24=1` | 코리더 목록(`world: 'corridor'`)의 매장. 시청점은 예전과 같아요 |
| `?bp24=demo` · `?bump24=demo` | 그 목록 + `BP24_DEMO`(크기가 다른 검증용 건물 3채) |
| `?bump24jeongja=0` | 정자점만 끔. 시청점·다른 매장은 그대로 |
| `?bump24jeongja=1` | 정자점을 명시해서 켬(기본값과 같음) |
| `?at=bump24-jeongja` | 정자점 문 앞으로 시작. 정자점이 꺼져 있으면 무시 |
| `?bp24game=1` | 문 앞 30초 장보기. 시청점은 `?bp24=1`이 같이 있어야 하고, 정자점만 켜져 있어도 동작 |

## 매장 하나 추가

`BP24_PLACEMENTS`에 한 줄을 넣어요. `world: 'corridor'` 는 아래 코리더 규칙, `world: 'jeongja'` 는 정자 `jeongja.json` 건물이에요.

```js
{ id: 'jeongja-xx', name: 'BUMP24 정자XX점', enabled: true, world: 'jeongja',
  flag: 'bump24xx', // 생략 가능. 있으면 ?bump24xx=0 이 이 매장만 끈다(기본 켜짐)
  building: 135, match: { x: -95.66, z: -93.14 }, front: '+x', side: null },
```

- `building`: `jeongja.json` 인덱스. `match` 중심과 2.5m 넘게 어긋나면 인덱스를 버리고 `match`에서 가장 가까운 건물을 써요.
- `front`: 간판이 바라보는 바깥 방향. `side: null` 이면 앞면만 유리.
- `recess`: 앞면을 건물 안으로 들이는 거리(m). 벽이 차도에 붙어 있을 때.
- `apron: false`: 앞 보도 데크·볼라드를 생략. 생략하지 않으면 시청점과 같은 앞마당(약 1.9m)이 밖으로 나가요.
- `enabled: false` 면 그 줄은 만들지 않아요.

코리더 매장은 지금까지와 같이 `world: 'corridor'` 로 넣어요. `BP24_LOCATIONS` 는 그 줄만 모아 둔 것이고, `?bp24=1` 이 있어야 생겨요.

```js
{ id: 'yatap-xx', name: 'BUMP24 야탑XX점', enabled: true, world: 'corridor', match: { x: 1234.5, z: -5678.9 } },
```

## 코리더 매장 하나 추가

코리더 줄만 따로 보면, 예전 `BP24_LOCATIONS`에 넣던 것과 같아요.

```js
{ id: 'yatap-xx', name: 'BUMP24 야탑XX점', match: { x: 1234.5, z: -5678.9 } },
```

- `match`: 대상 건물 외곽의 중심(월드 x, z)이에요. 반경 `r`(기본 3m) 안에서 가장 가까운 건물을 써요.
  - 좌표는 `public/corridor/tiles/X_Z.json`의 `b[].o`(외곽)에서 평균을 내면 돼요. 타일은 `floor(x/500)_floor(z/500)`예요.
- 이것만 적으면 나머지는 자동이에요.
  - 건물 외곽의 최소 넓이 회전 사각형(OBB)을 매장 틀로 써요. 기울어진 건물도 돼요.
  - 차도까지 가장 가까운 면을 앞면(유리 + 간판)으로 정해요.
  - 앞면과 이웃한 면 중 차도가 16m 안에 있는 면을 옆 유리(모퉁이 매장)로 정해요.
  - 크기는 최대 18 × 11m예요. 건물이 더 크면 모퉁이 쪽 일부만 매장이 되고, 나머지 1층은 벽으로 막아요.
  - 폭 9m 미만이나 깊이 6m 미만이면 작은 매장(키오스크) 배치를 써요. 뒤쪽 계산대 + 직원, 뒷벽 선반, 옆 냉장고로 구성돼요.
  - 폭 3.5m 미만, 깊이 3m 미만, 또는 1층을 비우면 위층이 2m 안 남는 건물은 건너뛰어요(`bp24.stats.skipped`).

### 직접 지정(선택)

| 키 | 값 | 뜻 |
|---|---|---|
| `front` | `'-z' \| '+z' \| '-x' \| '+x'` | 간판 면의 바깥 방향(월드 축) |
| `side` | 위 축 · `null` · `'auto'` | 옆 유리 면. `null`이면 앞면만 유리 |
| `box` | `{ x0, x1, z0, z1 }` | 축 정렬 매장 틀을 직접 지정. 실측과 맞출 때 써요 (예: #1 시청점) |
| `gf` | 4.4 | 1층(유리 + 간판 띠) 높이. 위층은 여기서부터 |
| `maxW` / `maxD` | 18 / 11 | 매장 최대 폭·깊이 |

## 동작 방식

- 타일을 불러올 때(`filter`) 매장 건물을 둘로 나눠요.
  - 충돌용 원본은 `nr: 1`(그리지 않음)이라 벽을 통과할 수 없어요.
  - 위층 사본은 `mh: gf`이에요.
- 타일을 빌드할 때(`build`) 그 타일의 매장을 모두 재질별로 합쳐요.
  - 외부, 간판, 유리, 발광, 바닥 빛, 실내, 상품이 각각 1개씩이에요.
  - 직원은 InstancedMesh 2개(몸·머리)예요.
  - 그래서 **타일당 9 draw call(+그림자 1)이고, 매장 수와는 상관없어요.** 낮에는 발광과 바닥 빛이 꺼져서 7이에요.
- 재질과 텍스처는 모든 매장이 같이 써요. 간판 1024×256과 상품 512×256 캔버스 2장이에요.
- 실내·상품·직원은 LOD예요. 매장 중심에서 170m(+같은 타일 매장 간 거리)보다 멀면 그리지 않아요.
- 직원은 게임 아바타(`createAvatar`)를 한 번 정점색으로 굳혀서 재사용해요. 숨쉬기와 고개 돌리기 애니메이션이 있어요.
- 타일이 풀리면 매장도 같이 해제돼요.

## 코리더 밖에서 쓰기

```js
import { placeBP24 } from './corridor/bp24.js';
const { tile, group, update } = placeBP24({ id: 'x', match: { x, z } }, tileJson);
// tile: 1층을 비운 타일 JSON(건물 메시는 이걸로 만들기), group: scene 에 추가, update(): 직원 애니메이션
```

## 확인

`?bp24=demo&hour=21`로 시청 앞(1600, -5755) 근처에 가면 돼요. 데모 매장 3곳은 같은 타일(3_-12)에 있어요.
콘솔의 `__jj.corridor.bp24.stores`로 매장별 W·D·옆 유리·거울 배치를 볼 수 있어요.
정자점은 `?at=bump24-jeongja` (장보기는 `&bp24game=1`). 콘솔의 `__jj.jeongjaBp24.stores`. `?bump24jeongja=0` 이면 칼튼호텔 1층은 예전 이마트24 상가 표시로 돌아가요.
