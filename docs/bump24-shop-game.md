# BUMP24 30초 장보기 미니게임 (1~3단계)

플래그: `?bp24=1&bp24game=1` (또는 `?bump24=1&bp24game=1`)

## 흐름
1. 매장 문 앞 → **들어가기** (E / 탭)
2. 지하철과 같은 페이드로 전용 실내 장면
3. 파란 장바구니 집기 → 5초 카운트다운 → 30초 장보기
4. 진열대 근처 **담기** (E / 큰 버튼 / 길게 눌러 연속)
5. 무게 80% 흔들림 · 초과 시 쏟아짐(점수 차감, 1초 경직, 바닥에서 다시 줍기)
6. 시간 종료 → 계산대 영수증 연출 → 결과 카드 (로컬 최고점)

## 아직 없는 것 (4~5단계)
- 서버 검증 · 진짜 리더보드 · BP 보상 · 칭호
