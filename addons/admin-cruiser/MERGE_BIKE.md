# 🏍️ Admin Cruiser (관리자용 바이크) 애드온 — 병합 가이드

Starbase 맵에 관리자가 타고 다닐 크루저 바이크 **1대**를 추가합니다. 참고 사진(무광/비비드 블랙 팻 크루저, 좌측면)을 three.js 프리미티브 + 캔버스 텍스처로 직접 모델링했습니다. 외부 GLB/이미지 에셋은 쓰지 않았고 **브랜드 로고·엠블럼·상표 문구는 전혀 없습니다** (UI 이름: "Admin Cruiser").

| 색상 | Vivid Black | 클리어코트 Physical 재질 `#0b0c0e` + 크롬/알루미늄 파츠 |

## 파일
- **신규** `src/entities/bikeModel.js` — 절차적 모델 (프레임, 45° V트윈, 크롬 프라이머리/에어클리너, 우측 2-in-2 머플러, 30° 레이크 포크, 풀백 핸들, 플로어보드, 사이드스탠드, 브레이크등 등). 조향 그룹·바퀴 회전·린 그룹·그립/머플러 마커를 `userData` 로 노출.
- **신규** `src/entities/adminBike.js` — 배치·탑승/하차·물리·라이더 자세·연기·HUD·멀티플레이.
- **수정** `src/main.js` — `// [bike]` 표시 5곳 (import, 생성, frame 업데이트, sendState, `__jj.bike`).
- **수정(버그 수정)** `src/net/remotePlayers.js` — 기존 코드에서 `// [terrain]` 주석 뒤에 `this.scene.add(mesh);` 가 같은 줄에 붙어 **주석 처리돼 원격 플레이어 아바타가 씬에 아예 안 보이던 문제**를 고쳤습니다(이번 작업 이전부터 있던 버그).
- **신규** `scripts/shots-bike.mjs` — Playwright 스크린샷 (`npx vite --port 5179` 실행 후 `node scripts/shots-bike.mjs`, `ONLY=smoke,lean` 로 일부만).
- `bike.patch` — 트럭 애드온 적용 상태 기준 `diff -ruN` (`patch -p1 < bike.patch` 로 검증 완료).

## 조작
- 바이크 근처(약 2.2 m)에서 **F** 또는 화면의 "F Ride / 탑승" 버튼 → 탑승. 다시 **F** → 왼쪽(스탠드 쪽)으로 하차 (막혀 있으면 오른쪽/뒤).
- **W/↑** 스로틀, **S/↓** 브레이크(정지 상태에서 아주 느린 후진), **A/D/←→** 조향, **Shift** 부스트.
- 휴대폰: 기존 조이스틱 그대로 사용.
- 마우스 드래그로 시점 회전, 1.2 초 뒤 자동으로 뒤쪽 체이스캠 복귀.
- 트럭 근처에선 F 가 트럭, 바이크 근처에선 바이크에 우선 탑승 (바이크 키 핸들러가 capture 단계에서 먼저 처리).
- 발사 쇼(L) 등으로 플레이어가 순간이동되면 자동 하차.

## 연출
- **조향**: 핸들바+포크+앞바퀴가 30° 레이크 축으로 실제 회전 (`δ = atan(휠베이스·요레이트/속도)`), 저속일수록 크게 꺾임. 주차 시 핸들 왼쪽으로 꺾인 상태 + 사이드스탠드로 약간 기울어짐.
- **린(기울기)**: `atan(v²/(R·g))` 물리식, 최대 약 39°. 테스트에서 46 km/h 선회 시 약 34°.
- **라이더 자세**: 할리식 크루저 포지션 — 상체 살짝 뒤로, 팔은 IK 로 풀백 핸들 그립을 잡고, 다리는 앞쪽 플로어보드에 발을 올림. 내 아바타의 색/모자/가방을 그대로 복제해서 태움.
- **머플러 연기**: 우측 머플러 끝에서 26개 스프라이트 풀로 은은한 회색 퍼프가 간헐적으로(짧은 연속 + 가끔 쉼) 나옴. 시동(탑승) 중에만, 주행 중엔 흩어져 더 옅어짐.
- 브레이크 시 테일램프 점등, 가감속에 따른 서스펜션 다이브.
- 충돌: 건물에 막힘(축 슬라이드), 주차된 바이크는 다른 플레이어/트럭에 장애물.

## 플래그
- `?bike=0` 바이크 비활성 (`__jj.bike === null`), 기본값 `?bike=1`.
- Starbase 맵에서만 생성. `?trucks=0`, `?launch=now`, `?tower=0` 과 함께 동작 확인.

## 멀티플레이
- 기존 트럭이 쓰는 `veh` 필드를 그대로 사용: `veh = { id: 900, ry, v, st }`. 트럭 코드는 id 900 을 무시하므로 충돌 없음.
- **서버/프로토콜 변경 불필요** (dev-relay 가 이미 veh 를 전달).
- 다른 사람이 타면: 내 화면의 바이크가 그 사람 위치로 이동하고, 그 사람 아바타 대신 바이크 위 라이더로 표시되며 연기도 나옴. 하차하면 원래 아바타 복귀.
- 검증: dev-relay(8799) + 두 페이지 → A 탑승·주행 시 B 화면의 바이크가 A 위치(오차 ~5 cm)로 이동, `remote` 설정, A 하차 후 해제. `shot-bike-multiplayer.png`.

## 한계 / 참고
- 아케이드식 물리(실제 이륜 동역학 아님), 넘어짐·윌리 없음. 평지 전용(지형 경사 미반영), 물 위 차단 없음.
- **관리자 인증 없음** — 지금은 누구나 탈 수 있음. 관리자 전용으로 하려면 `mount()` 앞에 권한 체크를 추가하세요.
- 주차 위치는 각 클라이언트 로컬(나중에 들어온 사람에겐 원래 스폰 근처 위치로 보임). 동시에 두 명이 타면 각자 화면에서 자기 바이크로 보임(1대 점유 잠금 없음).
- 아바타가 카툰 비율이라 실제 사람 대비 라이더가 다소 큼.
- 헤드라인 "정자역 3D" 표기는 기존부터 있던 것(이번 작업과 무관).
- 배포는 하지 않았습니다.
