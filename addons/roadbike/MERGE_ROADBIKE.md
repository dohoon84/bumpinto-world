# 🚴 CR·1 에어로 로드바이크 애드온 — 병합 가이드

Starbase 맵에 아드님이 탈 수 있는 **실물 크기 에어로 로드바이크 1대**를 추가합니다. 참고 사진(무광 블랙 에어로 로드 + 딥림 카본 휠)을 three.js 프리미티브와 캔버스 텍스처로만 직접 모델링했습니다. 외부 GLB나 이미지 에셋은 쓰지 않았습니다. 실제 브랜드 이름과 로고는 모두 가상의 이름으로 바꿨습니다(아래 "저작권 변경" 참고).

## 사양 반영
| 항목 | 값 | 반영 |
|---|---|---|
| 휠 | 700c (ISO 622), 타이어 28 mm | 타이어 외경 0.686 m, 림 높이 앞 45 mm / 뒤 65 mm 딥림 |
| 휠베이스 | 990 mm | `RB.WB` |
| 헤드각 | 72.5° | 조향축이 실제 각도로 기울어져 있습니다 |
| 크랭크 | 172.5 mm, 1x 체인링 + 12단 카세트 | 체인 텍스처가 케이던스에 맞춰 흐릅니다 |
| 무게 | 약 7.4 kg | `RB.MASS` (가감속 튜닝 기준) |
| 색상 | 무광 블랙 | 프레임 `#18191c` 카본, 흰색 데칼, 탄색 타이어 문구, 무지개 밴드 |
| 최고속도 | **정확히 50 km/h** | `VMAX = 50/3.6` 로 클램프(스프린트 중에도 넘지 않습니다) |

모델 디테일: 플라잉 탑튜브(시트스테이가 탑튜브 위로 연결), 일체형 에어로 핸들바(콕핏), 에어로 시트포스트·안장, 디스크 브레이크(앞뒤 로터·캘리퍼), 체인링·크랭크·페달, 리어 디레일러, 카세트, 체인, 브레이크 레버 후드, 스포크, 딥림 데칼, 타이어 사이드월 문구, 핸들 위 사이클 컴퓨터(라이브 화면), 주차용 리어 스탠드.

## 파일
- **신규** `src/entities/roadBikeModel.js` — 절차적 모델입니다. `RB`, `RB_PTS`, `drawComputer`, `createRoadBikeModel` 을 내보냅니다. `userData` 로 lean / steer / frontSpin / rearSpin / cassette / crank / pedals / grips / stand / chainTex / screen 을 노출합니다.
- **신규** `src/entities/roadBike.js` — 배치, 탑승·하차, 물리, 라이더 자세(IK), 사이클 컴퓨터 화면, HUD, 멀티플레이를 담당합니다.
- **수정** `src/main.js` — `// [roadbike]` 표시 부분(import, 생성, frame 업데이트, sendState, `__jj.roadbike`).
- **수정** `src/entities/adminBike.js` — `near()` 첫 줄에 "로드바이크 탑승 중이면 관리자 바이크 탑승 안 함" 한 줄을 추가했습니다(`/* [roadbike] */`).
- **신규** `scripts/shots-roadbike.mjs` — Playwright 스크린샷 스크립트입니다. `npx vite --port 5179` 를 실행한 뒤 `node scripts/shots-roadbike.mjs` 로 돌리시면 되고, `ONLY=side,computer` 처럼 일부만 찍을 수도 있습니다.
- `roadbike.patch` — 관리자 바이크 + 바이크 오디오 애드온이 적용된 상태를 기준으로 만든 `diff -ruN` 입니다.

## 적용 방법
1. 프로젝트 루트에서 `patch -p1 --dry-run < roadbike.patch` 로 먼저 확인하신 뒤 `patch -p1 < roadbike.patch` 를 실행해 주세요. (깨끗한 기준 복사본에 적용해서 결과가 현재 소스와 동일한 것을 확인했습니다.)
2. 패치가 충돌하면 zip 안의 `src/entities/roadBikeModel.js`, `src/entities/roadBike.js` 를 그대로 복사하시고, `main.js` / `adminBike.js` 는 `// [roadbike]` 부분만 손으로 옮겨 주시면 됩니다.
3. `npm run build` 로 빌드를 확인해 주세요(현재 기준 빌드 성공, 콘솔 에러 없음).

## 조작
- 자전거 근처(약 2 m)에서 **F** 키나 화면의 "F Ride / 탑승 · Road Bike" 버튼을 누르면 탑승합니다. 다시 **F** 를 누르면 하차합니다.
- **W/↑** 페달링(가속), **S/↓** 브레이크(정지 상태에서는 3 km/h로 천천히 뒤로), **A/D/←→** 조향, **Shift** 스프린트(가속과 케이던스 증가, 최고속도는 그대로 50 km/h).
- 휴대폰에서는 기존 조이스틱을 그대로 쓰시면 됩니다.
- 관리자 바이크나 트럭 근처에서는 기존 프롬프트와 겹치지 않도록 우선순위를 정리해 두었습니다. 로드바이크를 타고 있는 동안에는 다른 탈것 프롬프트가 숨겨집니다.

## 연출
- **사이클 컴퓨터(가상 브랜드 BUMPINTO)**: 핸들 앞 아웃프런트 마운트에 달려 있고, 실제 화면 텍스처를 **약 10 Hz** 로 다시 그립니다. 속도, 거리, 주행 시간, 케이던스, 평균 속도를 보여 줍니다. 탑승할 때마다 리셋되고, 0.3 m/s 미만에서는 자동으로 일시정지됩니다. 화면 오른쪽 아래 HUD에도 같은 정보가 나오며, 50 km/h에 도달하면 속도 바가 빨간색으로 바뀝니다.
- **물리**: 가속은 (스프린트 3.4 / 일반 2.4 m/s²) × (1 − 0.8·(v/Vmax)²) 이고, 공기저항 느낌의 관성 감속과 6 m/s² 브레이크가 있습니다. 최소 회전반경은 2.2 m입니다.
- **린(기울기)**: `atan(v²/(R·g))` 로 계산하고 최대 약 37°입니다. 저속에서는 핸들이 크게 꺾이고, 고속에서는 몸을 기울여 돕니다.
- **드라이브트레인**: 페달링 중에는 케이던스 70→95 rpm(스프린트 +10)으로 크랭크·페달·체인·카세트가 돌아갑니다. 관성 주행 때는 프리휠처럼 크랭크와 카세트가 멈춥니다.
- **라이더 자세**: 내 아바타를 복제해서 로드 포지션(상체를 숙이고 팔은 후드를 잡음)으로 태웁니다. 다리는 2-본 IK로 페달을 따라 움직이고, 흰 클릿 슈즈와 검은 장갑을 착용합니다.
- **노면 높이**: 도로 리본이 지면보다 6~10 cm 위에 그려져 있어서, 바퀴가 도로에 묻히지 않도록 노면 높이를 반영했습니다.
- 연기나 사운드는 없습니다(요청대로 조용한 자전거입니다).

## 플래그
- `?roadbike=0` 이면 로드바이크를 끕니다(`__jj.roadbike === null`). 관리자 바이크 등 다른 요소는 그대로 동작합니다.
- Starbase 맵에서만 생성되며, 관리자 바이크 옆(앞이나 뒤 4~7.5 m)에 주차됩니다. 자리가 없으면 스폰 근처 도로 가장자리에 둡니다.

## 멀티플레이
- 기존 `veh` 필드를 그대로 쓰며 `id: 901` 입니다(관리자 바이크와 겹치지 않습니다). `{id, ry, v, st, p}` 로 방향, 속도, 조향, 크랭크 위상을 보냅니다.
- 다른 사람이 타고 있으면 그 사람의 아바타가 자전거 위에 보이고, 나는 탈 수 없습니다. 그 사람이 나가거나 접속을 끊으면 자전거가 풀립니다.

## 한계
- 기존 카툰 아바타 체형이 그대로라서, 사실적인 자전거 위에서는 다소 통통해 보입니다.
- 변속(기어)은 시뮬레이션하지 않고, 케이던스만 속도에 맞춰 연출합니다.
- 주차 상태에서는 킥스탠드 대신 뒤 허브를 받치는 디스플레이 스탠드로 세워 둡니다.
- 헤드리스(swiftshader) 테스트에서는 프레임 dt 제한 때문에 시뮬레이션 시간이 실제보다 느리게 흘러, 제동·관성 장면의 타이밍이 실제와 조금 다릅니다.
- 키보드 F 로 하차하는 것은 자동 테스트로 확인했지만, 탑승은 스크립트에서 mount() 를 직접 호출하는 방식으로 확인했습니다.
- 위치에 따라 트럭이 약 3 m 옆에 주차될 수 있습니다.
- 공원이나 광장처럼 따로 높이가 있는 면은 도로처럼 보정하지 않았습니다(차이는 수 cm 수준입니다).
