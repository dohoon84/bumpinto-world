# CR·1 로드바이크 & 선물함

에어로 로드바이크. 모델 원본은 `MERGE_ROADBIKE.md`, 확인용 화면은 `shots/`.

## 선물함 수량

아이템은 종류마다 **보유 수량**이 있다. 화면 아이콘의 `×N`이 그 수다. 선물하면 그 아이템만 정해진 개수만큼 줄고, 받은 사람 수량은 같은 만큼 늘어난다. 다른 아이템 수량은 건드리지 않는다.

기준 목록은 `src/gifts/catalog.js`의 `GIFT_ITEMS`다. 서버, 로컬 릴레이, 화면이 이 배열만 본다. 목록에 없는 id는 보유로 받지 않는다.

들고만 있다가 나눠 주는 아이템은 여기 한 칸이면 된다.

```js
{
  id: 'item-id',
  icon: '🎁',
  name: '표시 이름',
  enName: 'Name',
  seedQty: 10,    // 아직 세상에 하나도 없을 때 레드 탱크 관리자에게 넣는 수량
  unit: 1,        // 선물 한 번에 넘어가는 개수
  unitName: '개', // 버튼에 붙는 단위. 자전거는 '대'
}
```

`seedQty`는 최초 1회다. 이미 누군가 수량을 가지고 있으면 다시 채우지 않는다. 로컬 릴레이와 목업에는 레드 탱크 계정이 없어서, 처음 접속한 사람에게 같은 수량을 준다.

보유 모양은 항상 `{ id, qty }` 배열이다. 내 화면 수량은 `src/gifts/holdings.js`에 모이고, 서버에는 `gift_holdings` 테이블에 사람·아이템별로 저장된다.

꺼내 쓰기·탑승처럼 수량 외에 동작이 있는 아이템은 카탈로그에 동작을 적지 않는다. `src/game.js`의 `customGiftIds`에 id를 넣고, 그 아래에서 소환 같은 버튼을 직접 연결한다. 로드바이크가 이 경우다. `vehId`가 있으면 보유가 1 이상일 때만 그 탈것을 다른 사람에게 보여 준다.

## 파일

| 파일 | 역할 |

| `src/gifts/holdings.js` | 지금 내 보유. 접속(`welcome`)과 선물 응답이 여기로 들어온다 |
| `src/game.js` | `customGiftIds`. 소환·탑승이 있는 아이템만 여기 연결 |

| `src/entities/roadBike/` | CR·1 모델, 탑승, 헬멧 머리. `catalog.js`는 id 별칭일 뿐 수량의 기준이 아니다 |

## 로드바이크 조작

- 보유가 1대 이상이면 선물함에서 **꺼내기**로 옆에 세운다. 근처에서 **F**로 타고 내린다. **수납**하면 세상에서 사라진다. 꺼내기는 대수를 줄이지 않는다. 장비 하나를 꺼내는 것이다.
- **선물**은 같은 지역에 있는 사람을 고르고 전화번호가 맞을 때만 1대가 넘어간다. 뱃지 숫자가 줄고, 받은 쪽은 늘어난다.
- 타고 있는 동안 머리는 헬멧 머리로 바뀐다. 평소 헤어·모자는 그 자리에 쓰지 않는다.
- 세워 두거나 타고 있는 동안 같은 지역의 다른 사람에게 자전거가 보인다. 보유가 없는 사람은 탈 수 없다.
- 접속이 끊기면 세워 둔 자전거는 사라지고, 보유 대수는 선물함에 남는다.

## 색은 다른 아이템

블랙 `roadbike-cr1`(veh 902)과 화이트 `roadbike-cr1-white`(veh 903)는 같은 사양이고 프레임 색만 다르다. 보유 수량도 따로다. 화이트 초기 수량은 10대.

수량은 자전거를 미리 10대 만들어 두는 숫자가 아니다. 선물함의 `×10`이고, 세상에 나오는 메시는 **꺼내기로 세운 1대**뿐이다. 꺼내기는 수량을 줄이지 않는다. 선물하면 내 수량에서 1이 빠지고 상대 수량에 1이 더해진다. 상대는 그 1대를 자기 선물함에서 꺼내야 자기 옆에 자전거가 생긴다.
